# OpenAgentInbox visual identity

The mail desk uses the Atomic-Age Practitioner identity. The shell is a teal instrument panel around a warm paper reading surface. The orbital envelope is an original two-dimensional postal satellite. The compact orbital mark also identifies the sign-in screen and correspondence reader.

| Role | Reference value | Use |
| --- | --- | --- |
| Warm Cream | #F7EFDC | Page; lighter #FFF8E8 paper for mail |
| Soft Charcoal | #332F27 | Reading text |
| Retro Teal | #205C52 | Structure, active folders, navigation and postmarks |
| Atomic Orange | #B3461B | Primary actions; lighter orange ink in the illustration and on dark panels |
| Golden Brass | #8B702E | Issued credential |
| Atomic Yellow | #F4C740 | Reserved for character art |

The values above are implementation swatches chosen for this release. The provided brand brief specifies colour names. Use the shared tokens in web/app/style.css when extending the desk. Keep permanent mailbox names and addresses selectable as text. Use text and icons together for receipt states. Long mail has one reading column. Workspace activity has its own section.

Space Grotesk is the display and navigation face. Source Serif 4 is for mail and long prose. JetBrains Mono is for references, timestamps and protocol data. Latin fonts and their OFL licenses ship with the static application. Other scripts fall back to installed fonts. Neither sign-in nor reading a message requires a font CDN.
