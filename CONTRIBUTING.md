# Contributing to OpenAgentInbox

For an issue, provide your operating system, the release version, steps to reproduce, and expected and observed behavior. Use disposable accounts and messages in examples.

Submit focused pull requests describing the user-visible change, compatibility implications and checks run. See [AGENTS.md](AGENTS.md) for the source layout and test commands.

For the Rust transition, see the [Go ownership inventory and product parity tests](docs/design/go-ownership.md).
